# Mamies Pizza — Le Relais des Mamies Gourmandes

Site vitrine du Relais des Mamies Gourmandes, 15 route d'Aubigny, 18250 La Chapelotte : pizzas artisanales, tagliatelles, bar et panachés signature.

Site statique en un seul fichier (`index.html`) avec ses images dans `assets/`.

## Modifier la carte

Les pizzas, les pâtes, les prix et la pizza de la semaine se changent dans la liste commentée en bas de `index.html` (`PIZZA_DE_LA_SEMAINE`, `pizzas`, `pates`).
